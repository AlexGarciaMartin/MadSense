SenseBridge modifications dated 2026-10-31: NativeHapticsQueue.cs added;

consumes each queued sample once, and outputs silence on underflow.

MadSense 0.3 changes (31 October 2026):
- Original vector comic/print UI and new logo in src/assets; no external artwork.
- Scoped input timing lease and opt-in ImmediateInputDelivery event-coalesced
  USB/IP completion with FIFO, unlink and teardown regression tests.
- Native haptics nearest/ties-even quantization; real PCM during speaker warmup;
  bounded recent haptic queue before consumption, preserving finite impulses.
- Opt-in ISO OUT latency aggregates, with scheduling unchanged and tests.
- MadSenseProbe source and lab-only comparison test are included; diagnostics
  are not automatically run during normal use. See evidence/comparison.

MadSense 0.4 changes (31 October 2026):
- Core/Utilities/MultimediaThread.cs added: MMCSS registration helper.
- Core/Utilities/PrecisionWait.cs added: high-resolution waitable timer sleep.
- DualSenseAudioForwarder: pump on a dedicated long-running thread, MMCSS
  "Pro Audio", tick wait through PrecisionWait instead of a yield spin.
- DualSenseDevice (physical): input read loop registered with MMCSS "Games".
- EmulationSettings: StrictNativeHaptics serialized as "strict_native_haptics";
  the upstream serialization test is updated accordingly.
- tests/Core/PrecisionWaitTests.cs added.
- src/: event-driven bridge worker, device-change wake, link-loss detection,
  live feedback signals, low-battery notice, tray autostart (--tray).
- BluetoothAudioReportBuilder / DualSenseDevice: the five session-block buffer
  bytes are settable (SessionBufferLengths); default unchanged at 0x40. MadSense
  sets the fifth byte to 0x20 (measured: pad-side haptic buffering 74 → 42 ms).
- tools/HapticLatencyProbe added (GPL-3.0): accelerometer-based tactile latency
  probe; includes a copy of the test-only WASAPI helper without NUnit.
- tests/Controllers/DualSense/Output/BluetoothAudioSessionBufferTests.cs added.

MadSense 0.4 speaker follow-up (1 November 2026):
- DualSenseAudioForwarder: speaker blocks queued during the eight-packet warmup are
  trimmed to the newest three (the post-warmup drain discarded alternate blocks);
  the first three lane openings are logged at Info. Forwarder tests adjusted and
  SpeakerAudioQueuedDuringWarmupIsTrimmedNotChopped added.
- src/Program.cs: forwarded speaker volume 0x64 (the pad's usable maximum) instead
  of the library default 0x50.
- tools/HapticLatencyProbe: --speaker-test mode (front-channel beeps through the
  bridge's render endpoint; --lead-ms, --gap-ms), --endpoint-volume, --ladder.
- EmulationSettings.ForwardSettings.SpeakerPreGain ("speaker_pre_gain", default 2);
  IDualSenseAudioOutputs.SetAudioOutput gained a preampGain parameter; the
  forwarder embeds the pre-gain in audio control 2 of the route report and of every
  audio-lane state block. MadSense sets 7 (heard on hardware). Serialization test
  expectation updated; forwarder test added.
- EmulationDualSenseAudioCapture: Info log of the first non-silent speaker chunk
  and of 5 s window peaks (what the host actually sends).
- IEmulationService.SetForwardingSpeaker(device, volume, preGain) added: applies
  both to the live forwarder without recreating the virtual controller.
- src/: speaker level (SpeakerLevels, Preferences {"mode","speaker"}, Bridge.
  SetSpeaker, ALTAVOZ DEL MANDO row and tray submenu); tools/ui-check.ps1
  (PrintWindow capture + UI Automation click) for UI evidence.
- Historical v0.4 ZIP: setup/ (install.ps1, uninstall.ps1, Instalar.cmd,
  Desinstalar.cmd) and tools/build-release.ps1. Its installer downloads
  usbip-win2 0.9.8.1 (BSD-2) and HidHide 1.5.230 (MIT) from their official
  GitHub releases with pinned SHA-256; those binaries were not inside that ZIP.

MadSense games and mods (feature/games-and-mods, 4 November 2026):
- src/Mods: receiver for the UDP protocol DualSense game mods use with DSX
  (JSON instructions on 127.0.0.1:6969). Protocol facts taken from the DSX v3
  mod-system README (Paliverse), the UDP servers of DualSenseY v2 (MIT) and DSZ
  (MIT) and DsxServer.cs of Zerk Sense 5 (MIT, florinp93). No code copied.
- DualSenseDeviceOutputs.StateFilter and EmulationService.SetOutputStateFilter
  (vendored core, GPL-3.0): an output-state rewrite hook so a mod can own a
  trigger, the lightbar or the player LEDs ahead of the game.
- src/Games/GameLibrary.cs: launcher detection (Steam, Epic, GOG, Ubisoft,
  Xbox, Windows uninstall list) following the approach of Zerk Sense 5's
  GameLibrary.cs (MIT); reimplemented.
- src/Games/catalog.json: a list of community mods. Each mod belongs to its
  author under its own license (stated per entry); MadSense downloads them
  from the authors' GitHub releases and redistributes nothing. Discovery
  sources: Awesome Adaptive Triggers (CC0, eVenent), the DualSenseX README,
  the DSZ compatibility table.
- PCGamingWiki data is fetched live, cached per user and shown with
  attribution (CC BY-NC-SA); it is not redistributed inside MadSense.
